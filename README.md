# task-7-fetch-api
A simple web application that fetches user data from the public API https://jsonplaceholder.typicode.com/users
 and displays it on the webpage. Built using HTML, CSS, and JavaScript (Fetch API).

✨ Features

Fetches user data using fetch()

Displays name, email, and address

Handles errors using .catch()

Includes a Reload Data button

Styled using CSS for clean UI

📁 Files

index.html – Structure of the page

style.css – Styling for the UI

script.js – Fetch API logic & DOM updates

🚀 How to Run

Open the project folder in VS Code

Open index.html

Right-click → Open with Live Server

Data will load automatically

Click Reload to fetch again

🌐 API Used

https://jsonplaceholder.typicode.com/users

📌 Outcome

You learn Fetch API, async JavaScript, JSON data handling, loops, and error handling.
